Lunar Navigator 0.10 - Windows x64

Extract the entire ZIP into one folder, then run LunarNavigator.exe.
Keep the DLLs, qt.conf, platforms and qml folders with the application.
Qt, Qt Design Studio and Python do not need to be installed on the target PC.

For a single download that installs all dependencies automatically, use
LunarNavigator-0.10-Setup.exe instead. It installs for the current Windows user
and creates a Start menu shortcut. Administrator access is not required.

The lunar datasets are embedded. The application works offline.
Drag to orbit, wheel to zoom, Lander and Region to inspect the selected site.
Calculate simulation runs the simplified descent and visibility analysis.

Source: https://github.com/pentalux/Lunar-Landing-Site-Navigator
